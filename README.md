# Student Management System (Java)

A menu-driven Student Management System developed using Java and Object-Oriented Programming (OOP) concepts.

## Features

- Add Student
- Display Students
- Search Student by Roll Number
- Update Student Details
- Delete Student
- Menu-Driven Interface

## Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- ArrayList
- Loops
- Conditional Statements
- Switch Case
- Scanner Class

## How to Run

1. Compile the program:

```bash
javac StudentManagementSystem.java
```

2. Run the program:

```bash
java StudentManagementSystem
```
